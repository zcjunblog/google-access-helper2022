# 隐私与权限

适用于仓库内 Google Access Helper 1.0.0 的实现。

## 必需权限

| 权限 | 实际用途 |
| --- | --- |
| `proxy` | 读取代理设置及其控制权，按用户操作启用配置或释放本扩展的设置 |
| `storage` | 将协议、主机、端口和范围保存在当前浏览器的 `chrome.storage.local` |

扩展不申请读取所有网站、浏览历史、标签页内容或其他扩展的权限，没有内容脚本。

## 可选网站权限

只有用户点击连接诊断时才申请以下网站的访问权限：

- `https://www.google.com/*`
- `https://chromewebstore.google.com/*`
- `https://scholar.google.com/*`

Chrome 的网站权限以 origin 范围授予；实现只对 [固定的三个端点](../extension/core.mjs) 发起检查。拒绝授权时不发起诊断请求，也不影响配置和快捷入口功能。可在浏览器的扩展详情中撤销网站访问权限。

诊断请求省略账号凭据、拒绝重定向、不读取响应正文，并只在当前弹窗展示结果，不保存诊断记录。检测请求会经过浏览器当前生效的代理与网络配置。

## 数据与网络

- 配置仅写入本地存储，不使用 `storage.sync` 或本项目的服务器。
- 本项目没有账号、遥测、分析 SDK、远程脚本或自动后台探测。
- 导入导出文件只包含版本和经过校验的代理配置字段，不支持密码、订阅密钥和认证账号。
- 点击服务快捷入口会打开对应网站，由该网站与浏览器正常处理其账号、Cookie 和内容；这不同于扩展发起的无凭据诊断请求。
- 代理服务和被访问网站由各自运营者管理，扩展无法替其保证隐私或可用性。
