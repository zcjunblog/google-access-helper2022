# 安装与使用

## 安装扩展

1. 从 [官方 Releases](https://github.com/zcjunblog/google-access-helper-mv3/releases/latest) 下载 `google-access-helper-1.0.0.zip`。
2. 解压后得到 `google-access-helper` 文件夹，确认里面直接有 `manifest.json`、`popup.html` 等文件。
3. 在 Chrome 地址栏打开 `chrome://extensions/`，开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择上一步的文件夹。
5. 打开工具栏扩展菜单，将 Google Access Helper 固定，再点击图标。

源码安装也可用：下载整个仓库后，选择其中的 `extension/` 文件夹。安装时无需运行终端命令，也不需要构建。不要选择整个仓库或 ZIP 文件。

扩展使用 MV3，声明的最低 Chrome 版本为 114。自动化实测环境为 Playwright 所带的当前 Chromium；其他 Chromium 浏览器需分别验证。受管理的浏览器可能禁止开发者模式或代理设置。

## 不配置代理也能用

顶部五个入口会打开 Google 搜索、Gmail、地图、学术和 Chrome 商店。网页是否能访问取决于当前网络，扩展不会自动替换你的网络服务。

## 配置代理

1. 从你使用的本地代理软件或服务获取**协议、主机、端口**。
2. 在“代理地址”填写域名或 IP，例如 `127.0.0.1`；在“端口”单独填写数字，例如 `7890`。示例不是内置服务器。
3. 根据代理服务器的协议选择 HTTP、HTTPS 或 SOCKS5；HTTPS 指连接到代理服务器的协议，不是你想打开的网站协议。
4. 选择“仅 Google 服务”或“全部网站”。
5. 点击“保存配置”只保存；点击“保存并启用”才修改浏览器代理设置。

支持 IPv4、IPv6 和 ASCII 域名。IPv4 使用无前导零的四段十进制格式；IPv6 可以填写 `::1` 或 `[::1]`。地址栏不接受 URL、用户名、密码或路径。此版本不提供代理认证凭据管理，也不导入服务商订阅。

## 两种范围

- **仅 Google 服务**：下列域名及其子域走指定代理，其他域名直接连接：`google.com`、`google.com.hk`、`google.com.tw`、`google.co.jp`、`google.co.uk`、`google.de`、`google.fr`、`google.ca`、`google.com.au`、`googleapis.com`、`gstatic.com`、`googleusercontent.com`、`ggpht.com`。
- **全部网站**：浏览器采用单一代理配置，保留 `<local>`、`localhost`、`127.0.0.1`、`[::1]` 的绕过规则及 Chrome 的隐式本地地址绕过行为。

Google 范围是明确的域名集合，不覆盖所有国家域名或所有关联服务。规则匹配的代理不可用时不会由本扩展添加直连后备项。实际代理行为仍受浏览器平台规则约束。

代理设置使用 Chrome 的 regular scope；未单独覆盖设置的无痕窗口可能继承该范围，具体取决于浏览器的扩展与无痕设置。

## 停用与状态

“已启用代理”表示 Chrome 的代理设置由本扩展控制，**不表示服务器已经连接成功**。状态卡会显示生效范围，并提示已保存配置是否与当前生效配置一致。

点击“停用代理”会清除本扩展保存的代理设置，恢复由原有系统、策略或其他适用设置控制。即使其他扩展正在接管，也可以清除本扩展的暂存设置，避免其之后意外恢复；此操作不修改其他扩展的设置，也不等同于强制直连。若其他扩展或管理策略控制了代理，本扩展会提示冲突并拒绝应用新配置。

## 连接诊断

点击“开始诊断”后，浏览器首次会请求三个具体网站的访问权限。允许后扩展检查：

- Google 搜索的 `generate_204` 端点。
- Chrome 商店首页。
- Google 学术首页。

每项最长等待 8 秒。结果分别显示连接成功、HTTP 错误、请求超时或网络连接失败，并附状态码和耗时。HTTP 429 等响应可能来自限流；重定向也可能表现为网络失败，不能据此单独断定代理线路故障。

诊断不会携带浏览器账号凭据，不跟随重定向，也不会自动后台运行。网站、网络或代理服务可能记录其自身收到的请求。更多说明见 [隐私与权限](privacy.md)。

## 导入、导出与更新

“导出配置”导出当前**已保存**的配置；尚未保存的输入不会写入文件。“导入配置”校验 JSON 后只保存，确认后再点击“保存并启用”。示例格式：

```json
{
  "version": 1,
  "profile": {
    "scheme": "http",
    "host": "127.0.0.1",
    "port": 7890,
    "scope": "google"
  }
}
```

更新时先导出配置，解压新安装包到原扩展文件夹，再在 `chrome://extensions/` 点击重新加载。若更换加载路径，浏览器可能将其视为另一个扩展。卸载扩展会清除对应的本地配置。
